设计心法

白环 = 硬件层（MOSS 的本体、永远在）· 绿瞳 = 信号层（生命/注意/状态，会动）。
状态全部只发生在绿层：居中呼吸眨眼 → 偏心巡环 → 熄灭。白色环在任何状态都不消失——"本体还在，只是没电/在忙"。

★ 动画拆解：三种"活法"各是什么

下面三个样品独立于全局状态、永远在动，幅度已放大到夸张档，方便认动作。看清之后，再用顶部面板和真实尺寸样品判断日常观感。

眨眼
已锁：标准 · 3.4s

看哪里：绿瞳。

绿瞳瞬间合拢成一条细线，再睁开，像眨一下。站里它 = "醒着、在听"。
频率你已锁「活泼」档。

② 解剖：11 × 11 像素网格

一个 11 格逻辑网格，所有尺寸都是它的整数倍放大（22/33/44/66/88px），保证像素锐利、不产生半像素模糊。

白环 描边层 · 永远在

● 外径 ≈ 4.7 格，环厚 ≈ 2 格（1px 描边在 22px 下仍可读）

● 白 = 站里"输出/结构"色（winbar 文字同为白）

● 在任何状态下都不消失 → "本体永远在"

绿瞳 信号层 · 会动

● 瞳 3×3 格；常态居中；思考时偏心 2 格沿环巡

● 绿 = 终端绿 #00ff41，站里唯一的"活"色（光标/链接 hover）

● 呼吸/眨眼/巡环/熄灭 = 四种"活法"，全在绿层

非目标：不加红色独眼（红线§6）、不做外壳造型、不用渐变/圆滑抗锯齿——它必须和整站的方块像素一致。

⑦ 无障碍与适配

  • 不以颜色/动画单独承载信息：灯旁边永远有文字（「MOSS 在线 / 思考中 / 休眠」），动画只是情绪层。
  • prefers-reduced-motion：降级为文字 + 静态亮/暗（熄瞳），不播动画。站里已有同款媒体查询，直接沿用。
  • 状态切换有过渡但克制：白环静止不动摇，动态只在绿层，视障/分心场景影响最小。
  • 尺寸上限：22/33/44/66 均为 11 格整数倍，无模糊；min 用 CSS 灯（非 SVG）保证 9px 可读。
  • 鼠标/键盘：休眠态灯上悬停/聚焦出现台词 tooltip（T1-1），不抢页面焦点。
