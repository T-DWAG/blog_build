候选形态对比（live 样品随全局状态动）

A

之眼体系（主推）

白环 + 绿瞳，同一图形按尺寸复用 · 10px 灯 / 22px 头像 / 33px mascot

在线 ↓ 试着切「思考中」看瞳仁巡环
  • 落点：winbar 路径旁状态灯（T1-1）· chat 窗头/消息头像（T1-8）
  • 状态：在线=绿瞳偶尔眨 / 思考=瞳仁沿环巡视 / 休眠=熄瞳转暗
  • 实现：1 份小 SVG（白环+绿瞳两图层）+ 3 条 CSS 动画，纯新增
  • 费用：零（canned 视觉，不走 LLM）

红线：白/绿双色，无红色独眼、无外壳造型 → 借"一只眼"结构语言，非复刻

B

M 徽章（备选 / favicon）

黑底反白粗 M + 绿角点呼吸 · 几何化字母，接设计稿 D3 的升级版

M 适合：favicon、浏览器页签、窗头"站牌"文字侧
  • 落点：页签图标 / chat 窗头左标（与 A 二选一或并排）
  • 实现：一个 div + border + ::after 绿点，最轻

红线：纯几何字母，无形象问题；是"分身徽章"而非 MOSS 本体

C

窗角驻留 mascot（彩蛋级）

放大版之眼住在 chat 窗角 · "驻站感"最重，靠动画演人设

上方案位③ 有它在窗角的样子（跟随状态动）
  • 人设联动：等访客 40s 眨眼看你（T1-4）· 检索中巡视（工具帧）· 429 闭眼
  • 成本：仍纯前端；比 A 多一段驻窗 JS + 定位，可后置

红线：意象是"眼+巡视"，不是电影里的球形摄像头本体
