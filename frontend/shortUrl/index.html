PROJECT DETAIL / 短链接服务

Go · go-zero · MySQL · Redis

短链接服务：
转链、跳转与安全治理。

一套面向高并发读、低延迟跳转场景的短链接系统。围绕转链校验、发号、编码、缓存穿透 / 击穿防护与 URL 安全， 逐步把接口做扎实：不只是"能生成短链"，而是"生成短链的每一步都有明确的失败处理"。

OVERVIEW

两条链路，一个核心约束

系统只做两件事：把长链接安全地变成短链接，把短链接快速地还原成跳转。约束是：写入路径要防止脏数据进库，读取路径要防止缓存失效时打垮数据库。

01

转链（Convert）

长链接可达性校验 → MD5 去重（避免同一 URL 重复占号）→ 短链循环检测（防止 A→B→A）→ 发号器取号 → Base62 编码 → 黑名单过滤 → 落库并返回完整短链。

幂等MD5黑名单
02

跳转（Show）

短码查询长链接 → 命中缓存直接 302，未命中时经布隆过滤器 + singleflight 保护数据库，最终写回缓存并跳转。

302布隆过滤器singleflight
03

约束：容错优先

每个失败点都有对应处理：取号失败重试、黑名单命中重新取号、缓存穿透用布隆过滤器拦截、并发击穿用 singleflight 合并请求。

容错可观测配置化

设计目标不是"跑通 demo"，而是让每条失败路径都有明确归宿。

REQUEST FLOW

请求链路拆解

用两张时序流程说明关键决策点，而不是罗列技术名词。

转链请求

  1. 参数校验 — 长链接格式、协议白名单（http/https）
  2. 可达性检查 — 请求目标 URL，判断是否可访问（当前已识别 SSRF 风险，见下文安全加固）
  3. MD5 去重 — 对长链接做摘要，查是否已存在映射，命中直接复用旧短码
  4. 循环检测 — 判断目标是否为本服务已生成的短链，防止 A→B→A 死循环
  5. 发号 + 编码 — 通过发号器接口取自增 ID，Base62 编码为短码
  6. 黑名单校验 — 编码结果命中保留词 / 敏感词则重新取号
  7. 落库 — 写入短码 → 长链接映射，返回 域名/短码

跳转请求

  1. 布隆过滤器判断 — 短码是否可能存在，不存在直接 404，避免无效查询打到数据库
  2. 缓存查询 — Redis 命中直接 302 跳转
  3. singleflight 合并 — 缓存未命中时，同一短码的并发请求合并为一次数据库查询，防止击穿
  4. 数据库回源 + 回写缓存 — 查到长链接后写回 Redis，设置过期时间
  5. 302 跳转 — 返回真实长链接

CORE CAPABILITY

六个值得展开的实现细节

这些不是简单的 CRUD，每一项都对应一个具体的工程问题。

01

发号器接口化

发号逻辑抽象为接口，默认实现基于 MySQL REPLACE INTO + LAST_INSERT_ID()，同一连接取号安全；接口层面预留 Redis / 号段模式实现，不绑定单一方案。

02

Base62 自实现编码

自增 ID 转 Base62 短码，字符表可配置。6 位即可覆盖约 568 亿组合；同时明确字符表打乱只提升遍历成本，不构成安全边界。

03

黑名单 + 配置化

短码生成后过滤保留词（如 api、health）与敏感词，命中则重新取号；域名、黑名单词表均走配置文件，不写死在代码里。

04

布隆过滤器防穿透

跳转请求先经布隆过滤器判断短码是否可能存在，拦截对不存在短码的无效查询，减少无谓的数据库压力。

05

singleflight 防击穿

缓存失效瞬间，同一短码的并发查询请求合并为一次数据库调用，其余请求等待结果复用，避免瞬时流量击穿数据库。

06

单元测试覆盖

对 Base62 编解码、URL 校验、MD5 去重等纯逻辑模块编写单元测试，保证核心算法在重构时行为不漂移。

SECURITY

安全复盘：诚实面对风险

可靠感来自边界和证据，包括承认当前实现的缺口。

风险

转链时的可达性检查会向用户提交的 URL 发起请求，若不加限制，攻击者可以构造指向内网地址（如 127.0.0.1、内网网段、云元数据接口）的链接，诱导服务端发起请求，构成 SSRF。

加固方案

协议限制：仅允许 http/https，拒绝 file、gopher 等协议

内网地址过滤：解析 URL 后校验目标 IP，拒绝私有网段与云元数据地址（如 169.254.169.254）

DNS 二次校验：域名解析结果同样要过内网 IP 过滤，防止 DNS rebinding

重定向限制：限制可达性检查的重定向跳转次数，并对每一跳都做同样的地址校验

超时控制：可达性检查设置严格超时，避免慢速请求拖垮服务
